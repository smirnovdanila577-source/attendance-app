# Трекер посещаемости — приложение

Фронтенд трекера: расписание ННГУ и ИГЭУ, посещаемость, домашние задания, профиль, еженедельный отчёт.
Сервер с API лежит в отдельном репозитории `attendance-backend` и работает на Render.

## Запуск на компьютере

1. Один раз: `npm install`
2. Запуск: `start.bat` (или `npm start`)

## Файлы

- `index.html` — разметка всех экранов
- `app.js` — основная логика: вход, синхронизация с облаком, расписание, посещаемость, ДЗ
- `ispu.js`, `ispu_groups.js`, `ispu.css` — поддержка ИГЭУ
- `profile.js`, `profile.css` — профиль, статусы, достижения
- `report.js`, `report.css` — еженедельный отчёт
- `main.js`, `preload.js` — оболочка Electron
